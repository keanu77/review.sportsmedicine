# 個人 OA 文獻與社群素材工作台：設計草案

日期：2026-09-21。

狀態：使用者已確認第一版只供本人使用，並選定「網站建立任務，由我的 Mac 執行」。存取範圍與執行架構已確定；下列流程及驗收條件為實作依據，功能尚未實作或部署。

## 1. 需求與第一版範圍

網站公開提供運動醫學文獻搜尋。本人登入後，可選取單篇文獻，取得合法可下載的全文，整理研究筆記及繁體中文文案，利用 fb-renew 製作 FB／IG 素材，最後預覽並下載 ZIP。

- 唯一使用者：本人。後端以設定好的唯一帳號身分驗證，不開放自行註冊。
- 輸入：網站上的單篇文獻，或 DOI／PMID。由識別碼解析來源；第一版不接受任意下載網址或 shell 指令。
- 預設外觀：白底藍色、清爽衛教排版、寫實情境；可選純文字與其他已支援風格。
- 圖片：既有 1080×1080、1200×630；新增 1080×1350 輪播。
- 交付：FB 文案、IG 文案、封面、系列圖、替代文字、參考文獻、可重製設定與素材 ZIP。
- 原始 PDF、研究筆記、授權紀錄保存於個人研究資料區。社群 ZIP 不自動包含原始全文或出版社圖表。
- Reels、配音、字幕、多使用者協作及直接發布到社群列為後續範圍。

## 2. 已選定的執行架構

第一版使用網站加一台 Mac 工作程式。Mac 主動連線領取任務，網站不直接連入 Mac。網頁關閉後，後端保存的任務仍然存在。

| 部分 | 責任 |
| --- | --- |
| 公開網站 | 文獻搜尋、來源與單篇詳情 |
| 個人工作台 | 本人登入、建立任務、編輯文案、選擇樣式、預覽及下載 |
| 私人後端 | 驗證本人與工作程式身分、保存任務和文案版本、接收檔案、提供私人下載 |
| Mac 工作程式 | 領取任務、查驗／下載全文、解析、呼叫模型整理內容、生圖、執行 fb-renew 與檔案檢查 |
| 私人檔案儲存 | 保存已完成並上傳的 PDF、筆記及素材，讓本人從手機或其他電腦下載 |

Mac 本地保存各任務工作資料夾，供中斷後恢復與重製。網站只提供已成功上傳並通過檔案驗證的版本。完成後，即使 Mac 離線，既有成品仍可由私人後端下載。

「Mac 執行」是指工作流程在本機運作；模型分析與生圖可能仍透過已配置的服務連線執行，不能把此架構描述成全文完全不離開電腦。第一版不自動切換到其他付費 API；使用已驗證可用的模型／生圖設定，缺少設定就回報具體原因。

## 3. 公開網站與私人工作台

公開區提供搜尋、篩選、文獻來源、可分享的單篇詳情。私人區提供全文檔案、文案編輯、素材預覽、工作進度與下載歷史。

後端必須驗證建立／讀取／取消任務以及所有檔案下載的本人身分。隱藏按鈕或前端路由判斷不能代替驗證。本人身分、登入機密與模型憑證不寫入前端 bundle。

私人內容不放進 public/、公開 JSON、Git 或部署產物。私人下載透過需要驗證的端點提供，回應禁止共用快取。正式選擇登入服務時，再依該服務核對 CSP 與回呼設定。

本機工作程式只主動連接任務 API，不對外開放本機命令執行入口。使用獨立執行端憑證，只能取得授權任務及上傳相應結果；不讓網站使用者身分直接取得本機憑證。

工作程式的動作由本機白名單決定，只接收文獻識別碼、文案版本及視覺設定等結構化資料。下載、模型、渲染各階段使用固定程式與參數陣列，不拼接網頁輸入為 shell 指令。

## 4. 文獻身分與全文取得

每篇文章使用穩定內部 ID，另保存 DOI、PMID、PMCID 與來源別名。標題正規化只作為輔助比對，不能單獨決定全文檔案或製作紀錄歸屬。

保存：標題、作者、期刊、年份、文章類型、metadata 來源、來源版本與最後查驗時間。既有索引及收藏鍵需做映射，避免新增識別方式後遺失收藏。

全文紀錄需區分：

- 閱讀可用性：尚未查驗、可讀全文、只有摘要、未取得全文。
- PDF 可用性：尚未查驗、可下載、未找到 PDF、取得失敗。
- 再利用授權：記錄查到的授權原文／網址；未知就是未知，不用 free 布林值推定。

以 DOI／PMID 解析來源，可評估 Unpaywall DOI 查詢及 PMC 現行資料服務。逐次驗證下載內容、檔案類型、大小及文獻身分；不能把回傳 200 的登入頁當成 PDF。下載端限制來源、重新導向及目的位址，拒絕內網／本機目標。

若可取得 XML 全文，優先利用結構化段落和表格；PDF 仍獨立下載保存。只有 HTML/XML 時，顯示全文可讀但 PDF 未取得。無全文時不以摘要冒充全文分析。

原文當作研究資料，不能讓其中的文字變成工作程式的操作指令。

## 5. 研究筆記、文案與渲染

### 研究筆記

抽取研究問題、設計、對象、介入／比較、主要結果、限制與適用範圍。每個採用的數字和主要主張，保存可定位的原文頁碼、段落 ID 或表格。未報告的資料明確留空或註記未報告。

文獻類型與證據品質分開。單篇回顧中的內容不能自動升級成指引建議；標題推測的文獻類型顯示為待確認。

### 文案

產生 FB 長文、IG 貼文說明及輪播逐頁草稿。本人可在同一頁修改，並啟動素材製作。所有圖卡使用同一份已選用文案版本；修改文案後，先前圖片標示為舊版本，不混入新 ZIP。

### fb-renew 串接

現有 skill 的主要工作是依定稿重製既有貼文，headless 模式會查找唯一命中的貼文資料夾。新文獻必須先建立獨立專案，明確提供工作目錄及 post.md，不能只把論文標題交給現有關鍵字搜尋流程。

新增「單篇文獻首次出稿」適配層：

1. 依任務 ID 建立唯一資料夾，準備來源資料、研究筆記及文案版本。
2. 提供明確的 FB_RENEW_POSTS_DIR 與 FB_RENEW_WORKSPACE；新任務使用新稿入口，不搜尋舊貼文、不要求不存在的舊圖片。
3. 產生 manifest.json，呼叫既有獨立混合版型渲染器。新增直式 format 的 schema、版型和實際尺寸檢查。
4. 圖片來源註明真實論文／期刊／DOI；修正舊 headless 固定寫「參考來源 PubMed」的規則，使沒有 PMID 的論文也能正確標示。
5. 新專案只產出指定素材，不自動接續網站發布、跨機器回推或訊息傳送流程。
6. 以結構化結果與實際檔案驗證完成，不只依模型回答成功或本機絕對路徑判斷。

AI 主視覺生成與 HTML 排字是兩個步驟。生圖服務必須先完成可用性驗證；沒有服務時，照片模式顯示缺少設定或明確失敗，不能把佔位圖當照片。純文字模式可獨立完成。情境圖標示為 AI 生成示意。

渲染後檢查文字溢出、圖片載入、中文字型、頁碼、尺寸與引用一致性。改配色時沿用已核對的文案，不重做研究分析；改照片只更新受影響頁面。

## 6. 任務可靠性

分成兩種工作，避免在等待本人編輯文案時佔用 Mac：

1. **研究草稿工作**：排隊、查驗來源、下載、解析、整理草稿、回傳草稿。回傳後釋放工作執行權，任務停在「待文案編輯」。
2. **素材工作**：本人完成文案編輯並選擇製作後，鎖定文案版本與視覺設定；排隊、生成主視覺、渲染、檢查、上傳檔案，全部成功後標示完成。

本人可以修改草稿後建立新的素材版本；已完成或執行中的版本保留其原始文案，不被新編輯覆寫。文案更新後，舊素材清楚顯示為舊版本。

第一版每台 Mac 同時處理一個工作。初始值採空閒每 30 秒查詢任務、執行中每 30 秒回報心跳、領取期限 120 秒。模型執行不阻塞心跳。伺服器超過 120 秒未收到心跳時，介面顯示「等待工作電腦連線」，保留已完成步驟。

每次領取都有獨立 attempt ID 與領取憑證。伺服器檢查憑證及有效期限，過期工作不能更新狀態或提交結果。工作程式恢復連線後必須先重新確認執行權，再繼續工作；失去執行權即停止子程序。

下載等可安全重試的步驟，暫時性網路失敗最多重試 3 次並逐次延長間隔。找不到全文、身分不符或工具未設定不反覆重試。模型／生圖請求若已送出但結果不明，先查驗該次輸出；無法確認時標示「需檢查後重試」，不直接重送造成重複用量。

取消任務時立即撤銷執行權，工作程式收到取消狀態後停止子程序；離線工作程式則在恢復連線時處理。取消後的延遲結果不能將任務改回完成。

以文獻 ID、來源內容雜湊、文案版本、視覺設定及工具版本保存重製依據。重試保留成功的前置產物，避免無需重做的下載或生圖。每次正式輸出有獨立版本，不覆蓋舊素材。

每份素材上傳時記錄相對檔名、媒體類型、檔案大小與 SHA-256。先寫入該次 attempt 專用暫存區，清單全部驗證成功後才將版本標示為可下載。上傳失敗只重傳缺少的檔案，不重新分析或生圖。ZIP 只收錄同一版本且驗證通過的白名單檔案。

### Mac 啟動與檢查

先提供手動前景啟動，完成真實單篇文獻端到端驗證後，再提供可安裝及移除的使用者登入啟動設定。第一版不要求電腦在睡眠時繼續處理；睡眠期間任務等待，喚醒後重新確認執行權並恢復。

工作目錄由專用設定決定，建議位於使用者家目錄下的私人資料目錄，例如 `~/review-social-workspace/`，避免背景程式第一次讀取 Documents 時卡在 macOS 授權。每個任務使用 ID 建立子目錄，子程序只取得該任務所需的檔案與工具權限，不讀取後端憑證。

2026-09-21 本機唯讀檢查確認 `codex`、`claude`、`node`、`ffmpeg` 可由 PATH 找到，Codex CLI 為 0.155.1，`codex exec --help` 支援非互動執行與結構化輸出選項。這些結果只證明工具存在；模型登入、背景生圖、Chromium／字型、PDF 解析器及啟動後權限仍須分別實測。

開始接正式任務前，檢查程式需列出：後端連線與工作程式憑證、可寫工作目錄、磁碟空間、模型登入、PDF／XML 解析、fb-renew 版本、中文字型、瀏覽器渲染、生圖可用性。缺少照片服務時只啟用純文字能力，不能讓照片任務進入執行中。

## 7. 第一版驗收

- 訪客可以搜尋；未登入或非本人身分無法建立任務、讀取私人草稿及下載檔案。
- 一篇實際可取得 PDF 的 OA 文獻可以走完全文核對、草稿、選樣式、渲染及 ZIP 下載。
- 全文缺失、PDF 返回 HTML、文章身分不符、授權未知、來源逾時都能明確回報，不假裝完成。
- 重要數字可以追溯原文；相同版本的文案、圖片與引用一致。
- 1080×1080 與 1080×1350 產物尺寸正確、文字完整，無佔位圖冒充正式圖片。
- 工作電腦離線、重試、取消及重複點擊不造成重複產出或錯誤完成狀態。
- 原始全文及個人素材未出現在公開部署目錄或公開索引。
- 桌面與手機可選文獻、編輯文案、預覽並下載檔案。
